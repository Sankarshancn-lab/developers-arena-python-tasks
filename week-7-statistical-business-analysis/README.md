
# Week 7: Statistical Business Analysis

## Project Overview

This project focuses on applying statistical techniques
to analyze business sales data and generate meaningful
business insights.

## Objectives

- Calculate descriptive statistics.
- Analyze probability distributions.
- Perform hypothesis testing.
- Analyze correlation between business metrics.
- Calculate confidence intervals.
- Perform linear regression.
- Generate actionable business recommendations.

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- SciPy
- Statsmodels
- Scikit-learn
- Jupyter Notebook

## Statistical Analysis

### 1. Descriptive Statistics
Mean, median, mode, variance and standard deviation.

### 2. Distribution Analysis
Histograms, density plots, box plots and normality testing.

### 3. Correlation Analysis
Pearson correlation and correlation heatmaps.

### 4. Hypothesis Testing
Independent samples T-test and One-Way ANOVA.

### 5. Confidence Intervals
95% confidence intervals and margin of error.

### 6. Regression Analysis
Multiple Linear Regression and model evaluation.

Model Performance:
- R-squared: 0.863
- MAE: 29724.69
- RMSE: 38244.39

### 7. Business Insights
Regional sales analysis and product performance analysis.

## Important Limitations

The supplied dataset does not contain marketing expenditure.
Therefore, marketing spend versus revenue analysis could not
be performed.

Total_Sales is calculated using Quantity multiplied by Price.
Regression results should not be interpreted as independent
causal effects.

5. Run all cells.

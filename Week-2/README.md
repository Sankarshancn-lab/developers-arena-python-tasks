\# Student Grade Calculator



\## Project Overview



The Student Grade Calculator is a Python-based application that accepts a student's name and marks, calculates the corresponding grade, and displays a performance message.



\## Features



\* Accepts student name and marks as input.

\* Calculates grades based on marks obtained.

\* Displays the student's result and feedback.

\* Uses conditional statements for grade calculation.

\* Provides a simple command-line interface.



\## Technologies Used



\* Python 3

\* Functions

\* Conditional statements

\* Command-line interface



\## Grading System



| Marks  | Grade |

| ------ | ----- |

| 90–100 | A     |

| 80–89  | B     |

| 70–79  | C     |

| 60–69  | D     |

| 0–59   | F     |



\## How to Run



1\. Install Python 3.

2\. Open Command Prompt.

3\. Navigate to the project directory.

4\. Run the following command:



```bash

python grade\_calculator.py

```



5\. Enter the student's name and marks when prompted.

\# Personal Introduction Program



\## About the Project



The Personal Introduction Program is a beginner-friendly Python

project developed as part of Developers Arena Task 1.



It asks the user for basic information and displays a personalized

welcome message.



\## Features



\- Collects the user's name

\- Collects the user's age

\- Collects the user's city

\- Collects the user's favorite hobby

\- Displays a personalized welcome message

\- Uses a simple and beginner-friendly interface



\## Technologies Used



\- Python 3.13



\## Concepts Demonstrated



\- Variables

\- Strings

\- User input using input()

\- Output using print()

\- F-strings

\- Comments

\- Basic string formatting



\## Requirements



Python 3.13 or a compatible Python 3 version.



No external libraries are required.



\## How to Run



1\. Install Python.

2\. Download or clone this repository.

3\. Open a terminal in the project directory.

4\. Run the following command:



&#x20;  py -3.13 personal\_intro.py
